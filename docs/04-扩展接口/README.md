# 04 扩展接口

## 本部分讲什么

本部分规定**用户与模型接触到的全部入口**:三个命令(只读,不触发模型)、六个工具(模型调用)、两段上下文注入、状态栏与任务面板。这些入口的形状是契约 —— 一旦改变,使用方式就变了。

```
用户 ──→ /deep-plan  /deep-plan-status  /deep-plan-docs
              │
              ↓ 注入纪律
        模型 ──→ deep_plan_start  deep_plan_record_variable
                 deep_plan_review  deep_plan_approve
                 deep_plan_revise  deep_plan_finish
                 deep_plan_task    deep_plan_step
              │
              ↓ 显示
        状态栏 + 任务面板
```
