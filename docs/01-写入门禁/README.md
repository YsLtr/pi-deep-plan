# 01 写入门禁

## 本部分讲什么

门禁是本项目的强制层:它在**工具调用发生之前**判定是否放行,不依赖模型自觉。本部分规定三条门禁各自的判定规则、它们认识的数据形状、以及它们拦不住什么。

```
        一次工具调用
             ↓
   ┌─────────┴─────────┐
   ↓                   ↓
写类工具              命令工具 (bash / powershell)
   ↓                   ↓
01-文件写入门禁       02-只读命令门禁
   ↓ 需要知道改哪个文件
03-锚点解析
```

`04-状态与持久化` 是上面三条共用的底座:门禁读的 `PlanState` 长什么样、怎么存下来。
