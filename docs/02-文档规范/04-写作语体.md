# 02 文档规范 / 04 · 写作语体

## 1. 适用范围

**【规则】** 本语体适用于 `docs/` 下全部正文,以及由 `deep-plan` 生成的规划文档。本语体规定的是**句子与标题的写法**,与 `01` 规定的布局、`02` 规定的骨架三者互不替代。

| 层 | 规定什么 | 由谁强制 |
| --- | --- | --- |
| `01` 布局 | 文件放在哪、叫什么 | 路径推导函数 |
| `02` 骨架 | 有哪些节、节里放什么 | `deep_plan_review` 的非空校验 |
| `04` 语体 | 句子怎么写、标题怎么起 | **无自动校验**,依赖纪律与审查 |

**【依据】** 语体没有可自动判定的判据(「这个说法是否规范」无法由正则判定),故本语体只能作为纪律写入,不能作为校验项。这一点与 `01` / `02` 不同,须在文档中显明,以免维护者误以为存在自动拦截。

**【规则】** 语体判据为「该句可被当作规范条款宣读」。

## 2. 七项禁令

**完整定义与全部替换对照表见 [`../INDEX.md`](../INDEX.md) §3.1。** 本节只列禁令与判据要点,避免两处定义漂移。

| # | 禁令 | 违规示例 | 判据 |
| --- | --- | --- | --- |
| 1 | 第三人称代词指代事物 | 「**它**拦什么」 | 代词要求回溯上下文;应重复名称 |
| 2 | 疑问句与疑问式表达 | 「锚点**是什么**」 | 疑问句把陈述义务转移给读者 |
| 3 | 「动词 + 什么」短语 | 「边界(不含**什么**)」 | 禁令 2 的口语化变体 |
| 4 | 啰唆用语 | 「**一句话**定位」 | 描述写作效果而非条款内容 |
| 5 | 口语词 | 「悄悄」「炸掉」「拖慢」 | 比喻的映射关系随读者而异 |
| 6 | 第二人称 | 「**你**可以改这一项」 | 规范文本的读者不特定 |
| 7 | 【依据】写成口语推理 | 「等于给出一条通道」 | 比喻与反问不可检验 |

**【规则】** 禁令 1 不约束 `其他` / `其余` / `其它`(限定词)。禁令 6 的替代方案是角色名「用户」「执行者」「维护者」或无人称陈述。

## 3. 不受约束的内容

**【规则】** 下列内容按原文保留,不适用 §2 各条:

| 内容 | 理由 |
| --- | --- |
| 代码块、标识符、命令行、正则 | 原文即契约 |
| 工具返回文案、`SKILL.md` 引文、提交信息模板 | 引用他人的原文 |
| 参数示例(`reason="<具体的冲突是什么>"`) | 字面量 |
| 说明「不该这样写」的反例引文 | 被引对象即违规样本 |
| 术语与固定语 | 见 `../INDEX.md` §4 |

**【规则】** 引用原文时不得为迁就语体而改写被引内容。被引内容本身不合语体时,在引文**之外**的叙述中说明,或在引文旁标注其为反例。

**【依据】** 引用一处被改写,引用即失去证据价值 —— 读者无法再据此核对原文。反例引文尤须保留原样:其违规形态本身就是被说明的对象。

## 4. 与其他产物的关系

**【规则】** 本语体同时约束三处产物,三者为同一套语体的三份表达:

| 产物 | 读者 | 语体要求 |
| --- | --- | --- |
| `docs/**` | 维护者 | 本文件全部条款 |
| `skills/deep-plan/SKILL.md` 与 `references/plan-format.md` | 模型,按需加载 | 同上;但其中的**命令式指令**(「不要写变更日志」)保留祈使语气 |
| `before_agent_start` 注入文案 | 模型,每轮 | 同上;祈使语气保留 |

**【规则】** 表格中「命令式指令」指直接指示行动的句子(「不得建 `decisions/`」「先改文档再改代码」)。这类句子是规范文本的正常构成,不属于「第二人称」或「口语化」;禁令针对的是叙述部分。

**【依据】** 纪律文本必须能被模型直接执行,因此需要祈使句。若把祈使句也改成陈述,指令会退化为描述,模型无从得知应当做什么。区分「叙述」与「指令」两种语气,使规范性与可执行性同时成立。

**【规则】** 修改本文件 §2 的任何一项时,必须同步 `../INDEX.md` §3.1 与 `../../skills/deep-plan/references/plan-format.md`。

**【依据】** 三处内容重复是刻意设计:三者的读者与载体不同,无法合并为一份(见上表)。内容重复即存在漂移风险,故以维护约定把同步写成硬要求(`../INDEX.md` §6 第 10 条)。

## 5. 已知限制

| # | 限制 | 说明 |
| --- | --- | --- |
| L1 | **无自动校验** | 「是否合规」不可由正则判定。违规只能靠人审查或按本表逐条比对 |
| L2 | **禁令清单不封闭** | 七项覆盖了已实际出现的违规形态,不能穷举中文口语的全部变体。遇到清单外的新形态,应补充本表而非放过 |
| L3 | **禁令 3 与禁令 4 的边界需判断** | 「X 什么」与啰唆用语都是口语变体,划分依赖「是否含疑问词」这一形式特征,边界个例需人工裁定 |
| L4 | **反例引文易被误改** | 反例按原样保留,但它与被禁止的写法字形一致;后续维护者据清单逐条 grep 时会命中反例。清单比对必须排除 §3 所列内容 |
| L5 | **三处同步靠人工** | 无工具检查 `docs/`、`SKILL.md`、注入文案三者的语体一致性 |
