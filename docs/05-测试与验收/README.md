# 05 测试与验收

## 本部分范围

本部分规定**改动的确认方式**:自动化测试覆盖的范围与不覆盖的范围;手工验收的执行步骤;改动时最易被破坏的位置。

```
自动化 (npm test)              手工 (按清单)
   ↓                              ↓
两个纯函数测试文件            门禁、工具、注入、UI
   ↓                              ↓
判定逻辑(可穷举)            集成行为(需真实环境)
```
