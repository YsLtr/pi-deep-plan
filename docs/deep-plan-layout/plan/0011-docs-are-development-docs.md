# 11. docs/ 定位为开发文档,INDEX.md 兼作入口

明确 `docs/` 就是本项目的**开发文档 (development)**,取代传统的根目录 `development.md`。
`docs/INDEX.md` 从「话题索引」提升为「开发文档入口」:保留话题表,另加本仓库的开发约定
(测试与类型检查命令、决策不进文档的约定)。`SKILL.md` 与 `plan-format.md` 写明这一定位,
防止以后有人在仓库根新建 `development.md`。
验收:三处文档都写明 `docs/` 取代根目录 `development.md`;`docs/INDEX.md` 含开发约定小节。
