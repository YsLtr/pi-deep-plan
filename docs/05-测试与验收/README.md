# 05 测试与验收

## 本部分讲什么

本部分规定**怎么确认改动是对的**:自动化测试覆盖什么、不覆盖什么;手工验收怎么逐步做;哪些地方最容易在改动时被破坏。

```
自动化 (npm test)              手工 (按清单)
   ↓                              ↓
两个纯函数测试文件            门禁、工具、注入、UI
   ↓                              ↓
判定逻辑(可穷举)            集成行为(需真实环境)
```
