# 02 文档规范

## 本部分讲什么

本部分规定**产物长什么样**:文档放在哪、一个话题由哪些文件组成、文件怎么命名、frontmatter 写什么、什么该进文档什么不该进、以及「为什么这么定」记在哪。

`../03-规划流程/` 讲的是**过程**(agent 怎么做);本部分讲的是**形状**(做出来的东西什么样)。两者可以分别改:形状是契约(会被门禁与工具读取),过程是纪律(只影响模型的写法)。

```
docs/
├── INDEX.md                  ← 全局索引:话题表 + 开发约定
└── <topic>/                  ← 一个话题 = 一个文件夹
    ├── <topic>.md            ← 总纲(唯一带 frontmatter 的文件)
    └── plan/
        ├── 0001-<slug>.md    ← 一个计划条目 = 一个文件
        └── 0002-<slug>.md
```

## 边界(不含什么)

| 不含 | 去哪 |
| --- | --- |
| 门禁怎么管 `docs/` 的写入权限 | `../01-写入门禁/01` |
| agent 怎么提问、怎么自问自答、怎么收尾 | `../03-规划流程/` |
| 任务的执行状态机 | `../04-扩展接口/03` |
| frontmatter 的解析实现 | `../01-写入门禁/04` 与 `../04-扩展接口/` |
| 文档内容的写作质量(措辞、证据密度) | `../03-规划流程/03` |
