# 00 总览

## 本部分范围

本部分是 pi-deep-plan 的**产品与架构契约**:本项目解决与不解决的问题范围;两个阶段各自的职责与硬约束;代码由哪几个文件承担、边界在哪;工程基线与验收方式。

这一层仅界定定义与位置、职责归属与验收方式,不规定某一机制的内部算法。
