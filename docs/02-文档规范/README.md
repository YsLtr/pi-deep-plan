# 02 文档规范

## 本部分的范围

本部分规定**产物的形态**:文档的放置位置、一个话题包含哪些文件、文件的命名方式、frontmatter 的字段、入文档与不入文档的内容范围、「规定理由」的记录位置,以及正文的写作语体。

`../03-规划流程/` 规定的是过程(agent 的执行方式),本部分规定的是形状(产物的形态)。两者可以分别改动:形状是契约,会被门禁与工具读取;过程是纪律,仅影响模型的写法。

```
docs/
├── INDEX.md                  ← 全局索引:话题表 + 开发约定
└── <topic>/                  ← 一个话题 = 一个文件夹
    ├── <topic>.md            ← 总纲(唯一带 frontmatter 的文件)
    └── plan/
        ├── 0001-<slug>.md    ← 一个计划条目 = 一个文件
        └── 0002-<slug>.md
```
