# 01 写入门禁

## 本部分范围

门禁是本项目的强制层:在**工具调用发生之前**判定是否放行,不依赖模型自觉。本部分规定三条门禁各自的判定规则、三条门禁认识的数据形状、以及三条门禁拦不住的情形。命令门禁的拒绝路径上另有拦截记录与临时放行两项设施,见 `05`。

```
        一次工具调用
             ↓
   ┌─────────┴─────────┐
   ↓                   ↓
写类工具              命令工具 (bash / powershell)
   ↓                   ↓
01-文件写入门禁       02-只读命令门禁
   ↓ 需要知道改哪个文件      ↓ 被拒时
03-锚点解析           05-拦截记录与临时放行
```

`04-状态与持久化` 是上述三条共用的底座:规定门禁读取的 `PlanState` 形状与持久化方式。`05` 规定命令门禁的拦截记录与一次性放行;一次性放行的凭据不在 `PlanState` 中。
