# 00 总览

## 本部分讲什么

本部分是 pi-deep-plan 的**产品与架构契约**:它解决什么问题、不解决什么问题;两个阶段各自的职责与硬约束;代码由哪几个文件承担、边界在哪;工程基线与验收方式。

这一层只回答「是什么、在哪里、谁负责、怎么验收」,不回答某一机制的内部算法。
